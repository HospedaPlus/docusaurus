# Arquitectura e infraestructura

HospedaPlus usa una arquitectura moderna, escalable y segura para ingerir, transformar, almacenar y visualizar datos. La solución se construye sobre una infraestructura en la nube con un enfoque híbrido, que combina servicios de AWS y tecnologías de código abierto.
