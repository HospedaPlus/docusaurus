<Note>
  **Seed de datos.** Todos los datos de las bases de datos simuladas se generan con un seed versionado en el repositorio. El seed usa una semilla fija para que los datos sean reproducibles, es idempotente, permite elegir el volumen (modo de desarrollo pequeño o modo completo), mantiene la integridad referencial con las APIs y los eventos simulados, inyecta los problemas de calidad de datos conocidos con una tasa configurable, y se ejecuta tanto en local como contra la base de datos en AWS.
</Note>

<AccessNote icon="alert" title="Problemas de calidad de datos conocidos">

Los datos llegan con los siguientes defectos, y las fuentes simuladas los inyectan a propósito:

- F1 tiene `"NULL"` como texto en los campos de agente y compañía, y valores de ADR negativos o extremos.
- Reservas con cero adultos, cero niños y cero bebés.
- Fechas de salida anteriores a la fecha de llegada.
- Monedas no indicadas en los archivos de agencias.
- Reservas duplicadas entre canales con leves diferencias en el nombre del huésped.
- Eventos de modificación que llegan antes del evento de creación.

</AccessNote>
