# <SourceTitleIcon icon="calendar" tone="blue" />F6 · Festivos y eventos <SourceType>API REST + CSV</SourceType>

Festivos del país de cada hotel, más un archivo de eventos locales como congresos y conciertos.

| Propiedad | Valor |

| Tipo | Datos reales, API pública + archivo |
| Ubicación | API pública [Nager.Date](https://date.nager.at) + CSV de eventos locales |

| Frecuencia | Anual (festivos) / semanal (eventos) |
| Volumen | < 1.000 filas/año |

</AccessTable>

## Cómo acceder

Los festivos vienen de la API de Nager.Date, por año y código de país. Por ejemplo, los festivos de Portugal en 2026:

```bash
curl https://date.nager.at/api/v3/PublicHolidays/2026/PT
```

Los eventos locales vienen de un archivo CSV que se actualiza cada semana.

## Cómo se usa

- Un festivo o evento local en una fecha agrega un multiplicador de precio adicional de 1,15.
- Nunca se permite sobreventa en fechas con un evento de categoría "alta".
