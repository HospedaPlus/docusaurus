# <SourceTitleIcon icon="currency" tone="teal" />F7 · Tasas de cambio <SourceType>API REST</SourceType>

Tasas de cambio diarias tomadas de una API pública. Son datos reales. La moneda de reporte es el peso colombiano (**COP**), así que todos los montos de la cadena se convierten a COP.

<AccessTable>

| Propiedad | Valor |
| --- | --- |
| Tipo | Datos reales, API pública |
| Ubicación | API [Frankfurter](https://frankfurter.dev) v2 |
| Método de acceso | API REST, sin llave |
| Frecuencia | Diaria, 01:00 UTC |
| Volumen | 5 monedas: USD (base), COP, EUR, MXN, BRL |
| Se almacena primero en | **S3 bronze, directo**: `bronze/f7_fx/fecha=YYYY-MM-DD.json` |

</AccessTable>

## Dónde se almacena

El DAG de Airflow `bronze_f7_fx` llama la API una vez al día y guarda la respuesta, sin cambios, en S3:

```bash
# Tasas del 2026-11-09 con USD como base, solo para COP, EUR, MXN y BRL
curl "https://api.frankfurter.dev/v2/rates?date=2026-11-09&base=USD&quotes=COP,EUR,MXN,BRL"
```

Después `silver_fx_daily` arma `silver/tasa_cambio_diaria/` (COP por unidad de cada moneda, para todos los días, repitiendo la última tasa en los días sin dato), que silver usa para pasar cada reserva a COP.
