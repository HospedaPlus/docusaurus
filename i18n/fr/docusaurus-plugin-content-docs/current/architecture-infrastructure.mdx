# Architecture et infrastructure

HospedaPlus s'appuie sur une architecture moderne, évolutive et sécurisée pour ingérer, transformer, stocker et visualiser les données. La solution repose sur une infrastructure cloud selon une approche hybride, qui combine des services AWS et des technologies open source.
