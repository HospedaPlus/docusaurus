# Sources de données

HospedaPlus Revenue intègre sept sources de données, de F1 à F7. F1, F6 et F7 sont des données publiques réelles. F2 à F5 sont **simulées** : l'équipe les construit en suivant la spécification du projet, et leur conception interne relève de la décision de l'équipe.

<Note>
  **Seed de données.** Toutes les données des bases simulées sont générées par un seed versionné dans le dépôt. Le seed utilise une graine aléatoire fixe afin que les données soient reproductibles, il est idempotent, permet de choisir le volume (petit mode de développement ou mode complet), préserve l'intégrité référentielle avec les API et les événements simulés, injecte les problèmes de qualité de données connus selon un taux configurable, et s'exécute aussi bien en local que sur la base de données dans AWS.
</Note>

<AccessNote icon="alert" title="Problèmes de qualité de données connus">

Les données arrivent avec les défauts suivants, que les sources simulées injectent volontairement :

- F1 contient `"NULL"` sous forme de texte dans les champs agent et société, ainsi que des valeurs d'ADR négatives ou extrêmes.
- Des réservations avec zéro adulte, zéro enfant et zéro bébé.
- Des dates de départ antérieures à la date d'arrivée.
- Des devises manquantes dans les fichiers des agences.
- Des réservations en double entre canaux, avec de légères différences dans le nom du client.
- Des événements de modification qui arrivent avant l'événement de création.

</AccessNote>
