# Où se trouvent les sources et comment y accéder ?

Les sources de données se trouvent sur des plateformes publiques et dans des systèmes simulés par l'équipe. Voici un résumé de l'emplacement de chacune et de la manière dont nous nous y connectons. Ouvrez chaque source pour en consulter le détail.

<AccessTable>

| Source | Emplacement | Méthode d'accès |
| --- | --- | --- |
| <SourceName icon="file" tone="purple">[F1 · Hotel booking demand](./f1-hotel-booking-demand.mdx)</SourceName> | Kaggle ([hotel-booking-demand](https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand)) | Téléchargement CSV, chargement historique unique |
| <SourceName icon="stream" tone="blue">[F2 · Événements du channel manager](./f2-channel-manager-events.mdx)</SourceName> | Flux d'événements simulé | Messages JSON, en continu |
| <SourceName icon="database" tone="teal">[F3 · Moteur de réservation propre](./f3-own-booking-engine.mdx)</SourceName> | Base de données PostgreSQL simulée, alimentée par un seed | Connexion à la base de données (SQL) |
| <SourceName icon="file" tone="sky">[F4 · Fichiers des agences traditionnelles](./f4-traditional-agency-files.mdx)</SourceName> | Fichiers hebdomadaires simulés de ~15 agences | Fichiers CSV / Excel |
| <SourceName icon="message" tone="purple">[F5 · Avis clients](./f5-guest-reviews.mdx)</SourceName> | API d'avis simulée | API REST paginée, quotidienne |
| <SourceName icon="calendar" tone="blue">[F6 · Jours fériés et événements](./f6-holidays-and-events.mdx)</SourceName> | API publique [Nager.Date](https://date.nager.at) + CSV des événements locaux | API REST + fichier CSV |
| <SourceName icon="currency" tone="teal">[F7 · Taux de change](./f7-exchange-rates.mdx)</SourceName> | API publique [Frankfurter](https://frankfurter.dev) | API REST, quotidienne |

</AccessTable>

<AccessNote title="Points d'attention sur l'accès">

- Aucun identifiant, aucune clé ni aucun mot de passe n'est stocké dans le dépôt ou dans les images de conteneurs.
- Les données personnelles des clients (nom, e-mail, téléphone) sont pseudonymisées avant d'atteindre la couche analytique.
- Les données des clients sont chiffrées.
- Les avis sont synthétiques : nous n'extrayons aucun avis réel des plateformes d'avis.

</AccessNote>
