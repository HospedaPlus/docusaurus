# Où se trouvent les sources et comment y accéder ?

Les sources de données se trouvent sur des plateformes publiques et dans des systèmes simulés par l'équipe. Chaque source est d'abord stockée à un endroit, d'où le pipeline Airflow la copie, brute, dans la couche **bronze** du lakehouse S3. Certaines sources arrivent d'abord dans **Neon** (PostgreSQL), d'autres vont **directement dans S3**. Ouvrez chaque source pour voir le détail.

<AccessNote title="Considérations d'accès">

- Aucun identifiant, clé ou mot de passe n'est stocké dans le dépôt ni dans les images de conteneurs. Demandez les chaînes de connexion à l'équipe.
- Chaque client se connecte à Neon avec son propre rôle : `app_writer` pour les simulateurs et les consommateurs, `etl_reader` (lecture seule) pour le pipeline et l'équipe.
- Les données personnelles des clients (nom, e-mail, téléphone) restent dans Neon : la table `guests` n'est jamais copiée dans le lac, et les noms de F4 et F5 sont pseudonymisés avant la couche analytique.
- Les avis sont synthétiques : nous n'extrayons pas de vrais avis des plateformes.

</AccessNote>
