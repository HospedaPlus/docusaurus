# Fontes de dados

O HospedaPlus Revenue integra sete fontes de dados, de F1 a F7. F1, F6 e F7 são dados públicos reais. F2 a F5 são **simuladas**: a equipe as constrói seguindo a especificação do projeto, e o desenho interno delas é uma decisão da equipe.

<Note>
  **Seed de dados.** Todos os dados dos bancos de dados simulados são gerados por um seed versionado no repositório. O seed usa uma semente fixa para que os dados sejam reproduzíveis, é idempotente, permite escolher o volume (modo de desenvolvimento pequeno ou modo completo), mantém a integridade referencial com as APIs e os eventos simulados, injeta os problemas de qualidade de dados conhecidos com uma taxa configurável e roda tanto localmente quanto no banco de dados na AWS.
</Note>

<AccessNote icon="alert" title="Problemas de qualidade de dados conhecidos">

Os dados chegam com os seguintes defeitos, e as fontes simuladas os injetam de propósito:

- F1 tem `"NULL"` como texto nos campos de agente e empresa, e valores de ADR negativos ou extremos.
- Reservas com zero adultos, zero crianças e zero bebês.
- Datas de saída anteriores à data de chegada.
- Moedas não indicadas nos arquivos das agências.
- Reservas duplicadas entre canais com pequenas diferenças no nome do hóspede.
- Eventos de modificação que chegam antes do evento de criação.

</AccessNote>
