# Arquitetura e infraestrutura

O HospedaPlus usa uma arquitetura moderna, escalável e segura para ingerir, transformar, armazenar e visualizar dados. A solução é construída sobre uma infraestrutura em nuvem com uma abordagem híbrida, combinando serviços da AWS e tecnologias de código aberto.
