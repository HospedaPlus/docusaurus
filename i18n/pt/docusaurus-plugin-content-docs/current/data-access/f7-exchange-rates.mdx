# <SourceTitleIcon icon="currency" tone="teal" />F7 · Taxas de câmbio <SourceType>API REST</SourceType>

Taxas de câmbio diárias obtidas de uma API pública. São dados reais. A moeda de relatório é o peso colombiano (**COP**), então todos os valores da rede são convertidos para COP.

<AccessTable>

| Propriedade | Valor |
| --- | --- |
| Tipo | Dados reais, API pública |
| Localização | API [Frankfurter](https://frankfurter.dev) v2 |
| Método de acesso | API REST, sem chave |
| Frequência | Diária, 01:00 UTC |
| Volume | 5 moedas: USD (base), COP, EUR, MXN, BRL |
| Armazenada primeiro em | **S3 bronze, direto**: `bronze/f7_fx/fecha=YYYY-MM-DD.json` |

</AccessTable>

## Onde é armazenada

O DAG do Airflow `bronze_f7_fx` chama a API uma vez por dia e guarda a resposta, sem mudanças, no S3:

```bash
# Taxas de 2026-11-09 com USD como base, só para COP, EUR, MXN e BRL
curl "https://api.frankfurter.dev/v2/rates?date=2026-11-09&base=USD&quotes=COP,EUR,MXN,BRL"
```

Depois `silver_fx_daily` monta `silver/tasa_cambio_diaria/` (COP por unidade de cada moeda, para todos os dias, repetindo a última taxa nos dias sem dado), que a silver usa para converter cada reserva para COP.
