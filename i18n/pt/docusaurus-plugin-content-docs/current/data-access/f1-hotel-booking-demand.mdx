# <SourceTitleIcon icon="file" tone="purple" />F1 · Hotel booking demand <SourceType>CSV</SourceType>

Dataset público com o histórico de reservas de um hotel urbano e um de férias em Portugal. No HospedaPlus é o histórico de dois hotéis da rede: `HP-PT-001` (City Hotel) e `HP-PT-002` (Resort Hotel). São dados reais, então não é simulada.

## Onde é armazenada

O arquivo nunca muda, então não passa pelo Neon. O DAG do Airflow `bronze_f1_historical`, executado uma vez à mão, baixa o arquivo do repositório `hospedaplus-csv` e o envia para `s3://…/bronze/f1_historical/`. Se o arquivo que já está no S3 tem o mesmo hash, ele não é enviado de novo. Depois `silver_f1_historico` o limpa em `silver/historico_f1/`, a base da análise de cancelamentos por tipo de depósito e antecedência (P1).

## Como acessar

Baixe do Kaggle, ou com a CLI do Kaggle usando um token pessoal de API (que fica fora do repositório):

```bash
kaggle datasets download -d jessemostipak/hotel-booking-demand --unzip
```

O repositório `hospedaplus-csv` também o perfila: `uv run -m buenavista_csv.f1_audit` grava a auditoria em `output/f1_audit/`.

## O que contém

Cada linha é uma reserva, com data de chegada, antecedência, canal de distribuição, segmento de mercado, ADR, indicador de cancelamento e tipo de depósito. As principais colunas são:

- `hotel`: `City Hotel` ou `Resort Hotel`.
- `is_canceled`, `lead_time`, `deposit_type`.
- `arrival_date_year`, `arrival_date_month`, `arrival_date_day_of_month`, `stays_in_weekend_nights`, `stays_in_week_nights`.
- `adults`, `children`, `babies`.
- `market_segment`, `distribution_channel`, `customer_type`, `agent`, `company`.
- `reserved_room_type`, `assigned_room_type`, `adr`, `reservation_status`, `reservation_status_date`.

<AccessNote icon="alert" title="Problemas de qualidade de dados conhecidos">

- `agent` e `company` trazem o texto `"NULL"` em vez de valores vazios.
- `adr` tem valores negativos e extremos que precisam ser tratados (outliers por IQR).
- Algumas reservas têm zero adultos, zero crianças e zero bebês.

</AccessNote>
