# Onde estão as fontes e como acessá-las?

As fontes de dados estão em plataformas públicas e em sistemas simulados pela equipe. Cada fonte é armazenada primeiro em um lugar e, de lá, o pipeline do Airflow a copia, em formato bruto, para a camada **bronze** do lakehouse no S3. Algumas fontes chegam primeiro ao **Neon** (PostgreSQL) e outras vão **direto para o S3**. Abra cada fonte para ver os detalhes.

<AccessNote title="Considerações de acesso">

- Nenhuma credencial, chave ou senha é guardada no repositório nem nas imagens de contêiner. Peça à equipe as strings de conexão.
- Cada cliente se conecta ao Neon com seu próprio papel: `app_writer` para os simuladores e consumidores, `etl_reader` (somente leitura) para o pipeline e a equipe.
- Os dados pessoais dos hóspedes (nome, e-mail, telefone) ficam no Neon: a tabela `guests` nunca é copiada para o lago, e os nomes de F4 e F5 são pseudonimizados antes da camada analítica.
- As avaliações são sintéticas: não extraímos avaliações reais das plataformas.

</AccessNote>
