# Extração e carga: como conectar ao Neon e ao S3

Todo o pipeline são **duas conexões**: ele **extrai** do Neon (e de algumas APIs) e **carrega** no S3. Esta página é o guia prático: que string cada uma precisa, um exemplo de cada string e o código para testar em um minuto.

:::warning[Só placeholders]
Todo valor entre `<sinais de menor e maior>` é um placeholder. As senhas reais ficam só no `.env` de cada máquina (nunca no git) e a equipe as compartilha em privado. Se uma senha já foi colada num chat ou num commit, troque-a no Neon (**Roles → Reset password**).
:::

## O processo em 6 passos

| Passo | De | Para | Como | Conexão usada |
| --- | --- | --- | --- | --- |
| 1. Extrair a cada hora | Neon `operation`, `streaming` | S3 `bronze/f2_ledger/`, `f3_reservations/`… | `SELECT … WHERE updated_at >= início AND < fim` → JSON Lines → `put_object` | `NEON_READ_URL` + role IAM |
| 2. Extrair toda noite | Neon (tabelas inteiras) | S3 `bronze/*_full/fecha=…/` | uma transação `REPEATABLE READ`, páginas de 50.000 linhas, `_SUCCESS` no final | `NEON_READ_URL` + role IAM |
| 3. Extrair de APIs e arquivos | F1, F5, F6, F7 (HTTP) | S3 `bronze/…` | `requests.get` → `put_object` | URLs base no `.env` + role IAM |
| 4. Carregar os arquivos do F4 | EC2 fontes | S3 `bronze/f4_agencias/semana=…/` | `s3.upload_file` a partir do `f4-weekly` | role IAM da EC2 fontes |
| 5. Transformar e carregar | S3 bronze / silver | S3 silver / gold | Spark `read.json` / `write.mode("overwrite").parquet` | role IAM (`s3a://`) |
| 6. Write-back | S3 gold | Neon `operation.cancellation_rate_by_lead` | `INSERT … ON CONFLICT DO UPDATE` | `NEON_WRITE_URL` |

## Neon (PostgreSQL)

### Anatomia da string de conexão

<UriAnatomy parts={[
  ['postgresql', 'esquema', 'airflow'], ['://'], ['etl_reader', 'role', 'neon'], [':'], ['<password>', 'senha', 'bad'], ['@'],
  ['ep-<endpoint-id>-pooler.us-east-2.aws.neon.tech', 'host (endpoint da branch)', 'aws'], ['/'], ['hospedaplus', 'banco de dados', 'neon'],
  ['?'], ['sslmode=require', 'SSL obrigatório', 'out'],
]} />

| Parte | Valor no HospedaPlus | Notas |
| --- | --- | --- |
| Esquema | `postgresql://` | `postgresql+psycopg2://` para SQLAlchemy |
| Role | `etl_reader` (só leitura), `app_writer` (leitura/escrita), `hospedaplus_owner` (mudanças de esquema) | Use a role com menos permissões que seja suficiente |
| Host | `ep-<endpoint-id>.us-east-2.aws.neon.tech` | Cada branch (`production`, `development`) tem seu próprio endpoint |
| `-pooler` | `ep-<endpoint-id>-pooler…` | Host com pool (PgBouncer): para muitas conexões curtas (simuladores, apps). Use o host **direto** para migrações e sessões com `SET` |
| Porta | `5432` | Padrão, pode ser omitida |
| Banco | `hospedaplus` | Não `neondb` |
| Parâmetros | `sslmode=require` (sempre), `channel_binding=require` (opcional, para o dono) | O Neon recusa conexões sem SSL |

### Strings de exemplo por uso

```bash title="Exemplos de .env (placeholders)"
# DAGs bronze do Airflow: só leitura
NEON_READ_URL=postgresql://etl_reader:<password>@ep-<endpoint-id>.us-east-2.aws.neon.tech/hospedaplus?sslmode=require
# gold_neon_writeback: grava operation.cancellation_rate_by_lead
NEON_WRITE_URL=postgresql://app_writer:<password>@ep-<endpoint-id>.us-east-2.aws.neon.tech/hospedaplus?sslmode=require
# Simulador F3 / consumidor F2 / carregador F4: muitas gravações curtas, host com pool
NEON_APP_URL=postgresql://app_writer:<password>@ep-<endpoint-id>-pooler.us-east-2.aws.neon.tech/hospedaplus?sslmode=require
# Mudanças de esquema e seed (init do db_simulated, migrações do buenavista-streaming): dono, host direto
NEON_OWNER_URL=postgresql://hospedaplus_owner:<password>@ep-<endpoint-id>.us-east-2.aws.neon.tech/hospedaplus?sslmode=require&channel_binding=require
```

**Onde copiar:** console do Neon → projeto `hospedaplus_database` → **Connect** → escolha a branch `production`, o banco `hospedaplus` e a role → copie a *connection string*. Ative **Connection pooling** para o host `-pooler`.

### Como conectar (teste em um minuto)

```bash title="psql"
# Conecta com a string completa e roda uma consulta (-c), depois sai
psql "postgresql://etl_reader:<password>@ep-<endpoint-id>.us-east-2.aws.neon.tech/hospedaplus?sslmode=require" \
  -c "SELECT count(*) FROM operation.reservations;"
```

```python title="Python · psycopg2 (o que os DAGs usam)"
# os lê variáveis de ambiente; psycopg2 é o driver do PostgreSQL
import os, psycopg2

# Abre a conexão com a string do .env e um cursor
with psycopg2.connect(os.environ["NEON_READ_URL"]) as conn, conn.cursor() as cur:
    # As 5 reservas alteradas mais recentemente
    cur.execute("SELECT code, status, updated_at FROM operation.reservations ORDER BY updated_at DESC LIMIT 5")
    # Percorre as linhas do resultado
    for row in cur.fetchall():
        # Imprime cada uma
        print(row)
```

```python title="Python · psycopg 3 (o que os simuladores usam)"
# psycopg é a versão 3 do driver do PostgreSQL
import os, psycopg

# Conecta (desiste após 10 s); fecha no fim do bloco
with psycopg.connect(os.environ["NEON_APP_URL"], connect_timeout=10) as conn:
    # Quem sou eu e que horas são no banco
    print(conn.execute("SELECT current_user, now()").fetchone())
```

```python title="Python · SQLAlchemy + pandas (notebooks, exploração)"
# pandas para tabelas em Python
import os, pandas as pd
# O SQLAlchemy gerencia as conexões para o pandas
from sqlalchemy import create_engine

# O SQLAlchemy precisa do driver no esquema: postgresql+psycopg2://
url = os.environ["NEON_READ_URL"].replace("postgresql://", "postgresql+psycopg2://", 1)
# pool_pre_ping testa a conexão antes de usá-la (o Neon fecha as ociosas)
engine = create_engine(url, pool_pre_ping=True)
# Roda a consulta e obtém um DataFrame
df = pd.read_sql("SELECT * FROM operation.hotels", engine)
```

### Erros comuns

| Mensagem | Causa | Solução |
| --- | --- | --- |
| `password authentication failed` | Senha ou role errada | Copie de novo a string em **Connect**; confira a branch |
| `could not translate host name` / `invalid URI` | A senha tem `@`, `#`, `/` ou `:` | Troque por uma só com letras, dígitos, `-` e `_`, ou codifique em URL (`@` → `%40`) |
| `SSL connection is required` | Falta `sslmode` | Adicione `?sslmode=require` |
| `permission denied for table …` | `etl_reader` tentando escrever | Use `app_writer` (`NEON_WRITE_URL`) só onde se quer escrever |
| `prepared statement … does not exist` | Recursos de sessão pelo `-pooler` | Use o host direto (sem `-pooler`) |

## S3 (lakehouse)

### Anatomia dos endereços

<UriAnatomy parts={[
  ['s3', 'esquema', 'airflow'], ['://'], ['hospedaplus-lakehouse-buenavista', 'bucket', 'aws'], ['/'], ['bronze', 'camada', 'bronze'], ['/'],
  ['f3_reservations', 'fonte', 'neon'], ['/'], ['fecha=2026-11-10', 'partição por data', 'gold'], ['/'], ['hora=14.jsonl', 'arquivo', 'out'],

- `s3a://hospedaplus-lakehouse-buenavista/silver/reservas`: o mesmo tipo de endereço com o esquema que o Spark (Hadoop) usa.
- `https://hospedaplus-lakehouse-buenavista.s3.us-east-2.amazonaws.com/<key>`: forma HTTP; o bucket é privado, então precisa de uma requisição assinada.

| O quê | Valor |
| --- | --- |
| Bucket | `hospedaplus-lakehouse-buenavista` (variável `S3_BUCKET`) |
| Região | `us-east-2` (variável `AWS_DEFAULT_REGION`) |
| Credenciais na AWS | Role IAM da EC2 (`hospedaplus-pipeline-role`): **sem chaves** |
| Credenciais num notebook | `aws configure` / `AWS_PROFILE`, ou `AWS_ACCESS_KEY_ID` + `AWS_SECRET_ACCESS_KEY` do seu usuário IAM |
| Testes locais (MinIO) | `S3_ENDPOINT_URL=http://localhost:9000` |

```bash title="Exemplo de .env"
# Nome do bucket do lago
S3_BUCKET=hospedaplus-lakehouse-buenavista
# Região do bucket
AWS_DEFAULT_REGION=us-east-2
# Só num notebook sem role (nunca na EC2, nunca no git):
# AWS_ACCESS_KEY_ID=<access-key-id>
# AWS_SECRET_ACCESS_KEY=<secret-access-key>
# Só para MinIO:
# S3_ENDPOINT_URL=http://localhost:9000
```

### Como conectar (teste em um minuto)

```bash title="AWS CLI"
# Lista as pastas dentro de bronze/
aws s3 ls s3://hospedaplus-lakehouse-buenavista/bronze/ --region us-east-2
# Imprime as primeiras linhas de um arquivo (- significa "na tela")
aws s3 cp s3://hospedaplus-lakehouse-buenavista/bronze/f7_fx/fecha=2026-11-10.json - | head
```

```python title="Python · boto3 (o que os DAGs bronze usam)"
# boto3 é o SDK da AWS para Python
import boto3, json

# acha sozinho a role IAM ou o seu perfil
s3 = boto3.client("s3", region_name="us-east-2")
# O bucket do lago
bucket = "hospedaplus-lakehouse-buenavista"

# carga (gravar)
s3.put_object(Bucket=bucket, Key="bronze/test/hello.json", Body=json.dumps({"ok": True}).encode(),
              ContentType="application/json")
# extração (ler)
body = s3.get_object(Bucket=bucket, Key="bronze/test/hello.json")["Body"].read()
# listar
for obj in s3.list_objects_v2(Bucket=bucket, Prefix="bronze/f7_fx/").get("Contents", []):
    # Nome e tamanho em bytes de cada arquivo
    print(obj["Key"], obj["Size"])
```

```python title="Python · enviar um arquivo inteiro (o que o f4-weekly faz)"
# Envia um arquivo local (caminho no disco, bucket, key no S3)
s3.upload_file("output/f4_agency_files/2026-W46/AG01.xlsx", bucket,
               "bronze/f4_agencias/semana=2026-W46/AG01.xlsx")
```

```python title="PySpark · ler bronze, gravar silver (o que os jobs silver/gold fazem)"
# Utilitários do projeto: sessão Spark e endereços do lago
from spark_jobs.session import spark, path

# local[*] + jars s3a + role IAM
s = spark("test")
# Lê todos os arquivos JSON Lines de um dia de bronze
raw = s.read.json("s3a://hospedaplus-lakehouse-buenavista/bronze/f3_reservations/fecha=2026-11-10/")
# Grava como Parquet em s3a://…/silver/reservas_test, substituindo o que havia
raw.write.mode("overwrite").parquet(path("silver", "reservas_test"))
```

### Erros comuns

| Mensagem | Causa | Solução |
| --- | --- | --- |
| `NoCredentialsError` / `Unable to locate credentials` | Sem role e sem chaves | Na EC2: associe a role IAM à instância. Num notebook: `aws configure` |
| `AccessDenied` | Falta `s3:PutObject` / `ListBucket` na role | Adicione a política acima |
| `PermanentRedirect` / `AuthorizationHeaderMalformed` | Região errada | `AWS_DEFAULT_REGION=us-east-2` |
| Spark `ClassNotFoundException: S3AFileSystem` | Faltam os jars | Use a imagem do pipeline (ela tem `hadoop-aws` e `aws-java-sdk-bundle`) |
| Spark `No FileSystem for scheme "s3"` | `s3://` usado no Spark | Use `s3a://` no Spark; `s3://` no boto3 e na CLI |

## Write-back para o Neon (a única carga no Neon)

# Insere uma linha, ou atualiza se (hotel, faixa de antecedência) já existe
UPSERT = """
INSERT INTO operation.cancellation_rate_by_lead (hotel_code, lead_bucket, cancel_rate, updated_at)
VALUES (%s, %s, %s, NOW())
ON CONFLICT (hotel_code, lead_bucket) DO UPDATE
   SET cancel_rate = EXCLUDED.cancel_rate, updated_at = EXCLUDED.updated_at
"""
