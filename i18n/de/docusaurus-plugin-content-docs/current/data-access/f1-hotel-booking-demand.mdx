# <SourceTitleIcon icon="file" tone="purple" />F1 · Hotel booking demand <SourceType>CSV</SourceType>

Öffentlicher Datensatz mit der Buchungshistorie eines Stadthotels und eines Ferienhotels in Portugal. In HospedaPlus ist er die Historie von zwei Hotels der Kette: `HP-PT-001` (City Hotel) und `HP-PT-002` (Resort Hotel). Es sind echte Daten, daher wird die Quelle nicht simuliert.

## Speicherort

Die Datei ändert sich nie, daher läuft sie nicht über Neon. Der Airflow-DAG `bronze_f1_historical`, einmal von Hand gestartet, lädt sie aus dem Repository `hospedaplus-csv` herunter und lädt sie nach `s3://…/bronze/f1_historical/` hoch. Hat die Datei in S3 bereits denselben Hash, wird sie nicht erneut hochgeladen. Danach bereinigt `silver_f1_historico` sie in `silver/historico_f1/`, die Grundlage der Stornoanalyse nach Anzahlungsart und Vorlaufzeit (P1).

## Zugriff

Lade sie von Kaggle herunter oder mit der Kaggle-CLI und einem persönlichen API-Token (das außerhalb des Repositorys bleibt):

```bash
kaggle datasets download -d jessemostipak/hotel-booking-demand --unzip
```

Das Repository `hospedaplus-csv` profiliert sie auch: `uv run -m buenavista_csv.f1_audit` schreibt das Audit nach `output/f1_audit/`.

## Inhalt

Jede Zeile ist eine Buchung, mit Anreisedatum, Vorlaufzeit, Vertriebskanal, Marktsegment, ADR, Stornokennzeichen und Anzahlungsart. Die wichtigsten Spalten sind:

- `hotel`: `City Hotel` oder `Resort Hotel`.
- `is_canceled`, `lead_time`, `deposit_type`.
- `arrival_date_year`, `arrival_date_month`, `arrival_date_day_of_month`, `stays_in_weekend_nights`, `stays_in_week_nights`.
- `adults`, `children`, `babies`.
- `market_segment`, `distribution_channel`, `customer_type`, `agent`, `company`.
- `reserved_room_type`, `assigned_room_type`, `adr`, `reservation_status`, `reservation_status_date`.

<AccessNote icon="alert" title="Bekannte Datenqualitätsprobleme">

- `agent` und `company` enthalten den Text `"NULL"` statt leerer Werte.
- `adr` hat negative und extreme Werte, die behandelt werden müssen (Ausreißer nach IQR).
- Einige Buchungen haben null Erwachsene, null Kinder und null Babys.

</AccessNote>
