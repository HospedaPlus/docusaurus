## Speicherort

**F6a · Feiertage → S3.** Am 1. jedes Monats (02:00 UTC) ruft der Airflow-DAG `bronze_f6_holidays` die API für Portugal, Kolumbien, Mexiko, Brasilien und Spanien auf, für das aktuelle und das nächste Jahr (Buchungen erfolgen Monate im Voraus), und speichert jede Antwort unverändert:

```bash
curl https://nagerholidays.com/api/v4/Holidays/PT/2026   # $NAGER_BASE_URL
# -> s3://…/bronze/f6_holidays/anio=2026/pais=PT.json
```

**F6b · Lokale Veranstaltungen → Neon, dann S3.** Die 33 Veranstaltungen liegen in einer CSV, die in `db_simulated` versioniert ist. `python -m seed events` lädt sie in `operation.local_events` (CI/CD lädt sie bei jeder Änderung der CSV neu), weil die Datenbank sie für die Überbuchungslimits braucht. Jeden Tag um 02:30 UTC kopiert der DAG `bronze_f6_events` die Tabelle nach `s3://…/bronze/f6_events/`.

Beide fließen in `silver/calendario_hotel/` (Hotel × Tag mit Feiertag, Veranstaltung und Wochenende).

## Verwendung

- Ein Feiertag oder eine lokale Veranstaltung an einem Datum fügt einen zusätzlichen Preismultiplikator von 1,15 hinzu.
- An Daten mit einer Veranstaltung der Kategorie „hoch“ ist Überbuchung nie erlaubt (`refresh_overbooking_limits()` setzt das Limit auf 0).
