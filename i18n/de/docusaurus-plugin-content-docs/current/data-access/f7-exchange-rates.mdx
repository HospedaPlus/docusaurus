## Zugriff

Die Frankfurter-API benötigt keinen Schlüssel. Zum Beispiel die aktuellen Kurse mit dem Euro als Basiswährung:

```bash
curl "https://api.frankfurter.dev/v1/latest?base=EUR"
```
