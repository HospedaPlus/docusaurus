<Note>
  **Daten-Seed.** Alle Daten in den simulierten Datenbanken werden von einem im Repository versionierten Seed erzeugt. Der Seed verwendet einen festen Zufalls-Seed, damit die Daten reproduzierbar sind, ist idempotent, erlaubt die Wahl des Volumens (kleiner Entwicklungsmodus oder Vollmodus), wahrt die referenzielle Integrität mit den simulierten APIs und Events, fügt die bekannten Datenqualitätsprobleme mit einer konfigurierbaren Rate ein und läuft sowohl lokal als auch gegen die Datenbank in AWS.
</Note>

<AccessNote icon="alert" title="Bekannte Datenqualitätsprobleme">

Die Daten weisen die folgenden Mängel auf, die von den simulierten Quellen gezielt eingefügt werden:

- F1 enthält `"NULL"` als Text in den Feldern für Agent und Firma sowie negative oder extreme ADR-Werte.
- Buchungen mit null Erwachsenen, null Kindern und null Babys.
- Abreisedaten, die vor dem Anreisedatum liegen.
- Fehlende Währungsangaben in Reisebürodateien.
- Kanalübergreifend doppelte Buchungen mit leichten Abweichungen im Gästenamen.
- Änderungs-Events, die vor dem Erstellungs-Event eintreffen.

</AccessNote>
