# Where are the sources and how to access them?

The data sources live in public platforms and in systems simulated by the team. Each source is stored first in one place, and from there the Airflow pipeline copies it, raw, to the **bronze** layer of the S3 lakehouse. Some sources land first in **Neon** (PostgreSQL), others go **straight to S3**. Open each source for its details.

<AccessNote title="Access considerations">

- No credential, key or password is stored in the repository or in container images. Ask the team for the connection strings.
- Each client connects to Neon with its own role: `app_writer` for the simulators and consumers, `etl_reader` (read-only) for the pipeline and the team.
- Guest personal data (name, email, phone) stays in Neon: the `guests` table is never copied to the lake, and names in F4 and F5 are pseudonymized before the analytics layer.
- Reviews are synthetic: we do not extract real reviews from review platforms.

</AccessNote>
