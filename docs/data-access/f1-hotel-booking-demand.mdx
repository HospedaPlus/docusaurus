# <SourceTitleIcon icon="file" tone="purple" />F1 · Hotel booking demand <SourceType>CSV</SourceType>

Public dataset with the booking history of one urban hotel and one vacation hotel in Portugal. In HospedaPlus it is the history of two hotels of the chain: `HP-PT-001` (City Hotel) and `HP-PT-002` (Resort Hotel). It is real data, so it is not simulated.

## Where it is stored

The file never changes, so it does not go through Neon. The Airflow DAG `bronze_f1_historical`, run once by hand, downloads it from the `hospedaplus-csv` repository and uploads it to `s3://…/bronze/f1_historical/`. If the file already in S3 has the same hash, it is not uploaded again. `silver_f1_historico` then cleans it into `silver/historico_f1/`, the base for the cancellation analysis by deposit type and lead time (P1).

## How to access it

Download it from Kaggle, or with the Kaggle CLI using a personal API token (which stays out of the repository):

```bash
kaggle datasets download -d jessemostipak/hotel-booking-demand --unzip
```

The `hospedaplus-csv` repository also profiles it: `uv run -m buenavista_csv.f1_audit` writes the audit to `output/f1_audit/`.

## What it contains

Each row is a booking, with its arrival date, lead time, distribution channel, market segment, ADR, cancellation flag and deposit type. The main columns are:

- `hotel`: `City Hotel` or `Resort Hotel`.
- `is_canceled`, `lead_time`, `deposit_type`.
- `arrival_date_year`, `arrival_date_month`, `arrival_date_day_of_month`, `stays_in_weekend_nights`, `stays_in_week_nights`.
- `adults`, `children`, `babies`.
- `market_segment`, `distribution_channel`, `customer_type`, `agent`, `company`.
- `reserved_room_type`, `assigned_room_type`, `adr`, `reservation_status`, `reservation_status_date`.

<AccessNote icon="alert" title="Known data quality issues">

- `agent` and `company` contain the text `"NULL"` instead of empty values.
- `adr` has negative and extreme values that must be treated (IQR outliers).
- Some bookings have zero adults, zero children and zero babies.

</AccessNote>
