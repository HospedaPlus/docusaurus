# Data Sources

HospedaPlus Revenue integrates seven data sources, from F1 to F7. F1, F6 and F7 are real public data. F2 to F5 are **simulated**: the team builds them following the project specification, and their internal design is a team decision.

<Note>
  **Data seed.** All data in the simulated databases is generated by a seed versioned in the repository. The seed uses a fixed random seed so data is reproducible, is idempotent, lets us choose the volume (small development mode or full mode), keeps referential integrity with the simulated APIs and events, injects the known data quality issues at a configurable rate, and runs both locally and against the database in AWS.
</Note>

<AccessNote icon="alert" title="Known data quality issues">

The data arrives with the following defects, and the simulated sources inject them on purpose:

- F1 has `"NULL"` as text in the agent and company fields, and negative or extreme ADR values.
- Bookings with zero adults, zero children and zero babies.
- Departure dates earlier than the arrival date.
- Missing currencies in agency files.
- Bookings duplicated across channels with slight differences in the guest's name.
- Modification events that arrive before the creation event.

</AccessNote>
